02

Hosting der Website

Die derzeitige Testversion dieser Website kann über GitHub Pages bereitgestellt werden. Anbieter dieses Dienstes ist GitHub.

Beim Aufruf einer über GitHub Pages bereitgestellten Website können durch GitHub technisch erforderliche Verbindungsdaten verarbeitet werden.

Nach Angaben von GitHub werden insbesondere IP-Adressen von Besuchern von GitHub-Pages-Websites zu Sicherheitszwecken protokolliert.

Weitere Informationen zur Datenverarbeitung durch GitHub sind in den Datenschutzinformationen von GitHub verfügbar.

Sobald der Shop auf einen anderen Hostinganbieter umzieht, wird dieser Abschnitt entsprechend angepasst.

03

Technische Server- und Zugriffsdaten

Beim Aufruf einer Website werden technisch bedingt Daten zwischen deinem Endgerät und dem jeweiligen Webserver übertragen.

Hierzu können insbesondere gehören:

  • IP-Adresse
  • Datum und Uhrzeit des Zugriffs
  • aufgerufene Seite bzw. Datei
  • Browsertyp und Browserversion
  • Betriebssystem
  • Referrer-Informationen
  • technische Fehler- und Sicherheitsinformationen

Die Verarbeitung erfolgt insbesondere, um die Website technisch bereitzustellen sowie Stabilität und Sicherheit zu gewährleisten.

04

Warenkorb und Local Storage

Unser Shop verwendet derzeit den lokalen Speicher deines Browsers (Local Storage), um deinen Warenkorb auf deinem Gerät zu speichern.

Dabei werden insbesondere Produktnummern und die von dir gewählten Mengen gespeichert.

Diese Speicherung ist erforderlich, damit dein Warenkorb beim Wechsel zwischen Seiten oder beim erneuten Laden der Website erhalten bleibt.

Wichtig:

Die Warenkorbdaten werden in der aktuellen Testversion ausschließlich lokal in deinem Browser gespeichert.

Du kannst diese Daten jederzeit löschen, indem du den Website-Speicher bzw. die Browserdaten für diese Website löschst.

Sollten zukünftig Analyse- oder Marketingdienste eingebunden werden, wird diese Datenschutzerklärung entsprechend ergänzt und, soweit erforderlich, zuvor eine Einwilligung eingeholt.
